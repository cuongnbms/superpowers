# show-me Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A standalone, user-invoked `show-me` skill that draws what is hard to picture in chat (mockups, diagrams, data shapes, code paths) in a browser tab served by a small Python server, on the Mac and on devtuf.

**Architecture:** One standard-library Python script (`skills/show-me/scripts/server.py`) is both the CLI (`start|status|stop`) and the HTTP server; it wraps agent-written HTML fragments in one frame template (`frame.html`, look C "workbench") that polls for new screens and renders Mermaid, highlighted code, and the component kit. `SKILL.md` tells the agent when and how to use it; `references/components.md` is the markup catalog. Server behavior is pinned by `unittest`; the frame by a contract test plus screenshots; the skill by Opus-subagent evals and `claude -p` trigger checks, all run together in Task 6.

**Tech Stack:** Python 3.8+ standard library (`http.server`, `argparse`, `json`, `secrets`, `hmac`, `subprocess`), `unittest`; HTML/CSS/JS; Mermaid 11.4.1 and highlight.js 11.9.0 from CDNs; Geist and Geist Mono from Google Fonts.

**Spec:** `docs/superpowers/specs/2026-10-09-show-me-design.md` (sample page: `docs/superpowers/specs/2026-10-09-show-me-looks.html`, open with `?look=workbench`)

## Global Constraints

- Branch: `dev` (your human partner chose to stay on it). Do not edit anything under `skills/brainstorming/`.
- Python: standard library only, must run on Python 3.8 (devtuf has 3.12, the Mac 3.14): no `str.removeprefix`, `Path.is_relative_to`, `match`, `X | Y` or `list[str]` annotations evaluated at runtime; use `typing`.
- Test command, from the repo root: `python3 -m unittest discover -s tests/show-me -v`. Tests load `server.py` with `importlib.util.spec_from_file_location`.
- Layout: skill dir `skills/show-me/`; session dir `<project-dir>/.superpowers/show-me/` holding `screens/`, `server.json`, `server.log`, and `.gitignore` with exactly `*\n`.
- CLI: `python3 server.py start [--project-dir DIR] [--host H] [--url-host H] [--port N] [--idle-minutes FLOAT] [--foreground]`, `status [--project-dir DIR]`, `stop [--project-dir DIR]`. `start` prints one JSON line with exactly the keys `url, screen_dir, session_dir, port, pid, reused`; `status` prints the same keys (with `reused: true`) and exits 0 when running, exits 1 printing nothing when not; `stop` exits 0 always. Errors go to stderr as `show-me: <message>` with exit 1. Printed paths are `Path.resolve()`d.
- `--project-dir` default: `git -C <cwd> rev-parse --show-toplevel`; when that fails, `<tempfile.gettempdir()>/show-me-<first 12 hex of sha1(str(cwd.resolve()))>`.
- `server.json` keys exactly `pid, port, host, url, key, started_at`; `started_at` = `datetime.now().astimezone().isoformat(timespec="seconds")`; the serving process sets `pid` to `null` when it exits cleanly (stop, idle), and keeps the rest.
- Liveness ("our server is running") = `server.json` pid is alive (`os.kill(pid, 0)`) AND `GET http://<probe>:<port>/api/screens?key=<key>` returns 200 within 1 s, where probe = `127.0.0.1` when host is `0.0.0.0`, else host. `stop` sends SIGTERM only to a live server by this definition, waits up to 5 s for it to exit, and writes `pid: null` itself if it is still listed.
- Key: `secrets.token_hex(16)` (32 lowercase hex), created once per session dir and reused on restart when `server.json` holds a valid one. A request passes when `?key=` or the cookie `show_me_key_<port>` equals the key under `hmac.compare_digest`; a passing query key sets `Set-Cookie: show_me_key_<port>=<key>; HttpOnly; SameSite=Strict; Path=/`. Everything else is 403, checked before routing.
- Hosts: `derive_hosts(env, host, url_host)`: when `SSH_CONNECTION` has at least 3 whitespace-separated fields, bind `0.0.0.0` and URL host = field 3; otherwise bind `127.0.0.1`, URL host `localhost`; `--host` / `--url-host` override each half. URL = `http://<url_host>:<port>/?key=<key>`.
- Port: `--port` if given (busy → `show-me: port N is in use`, exit 1); else the stored port; if that bind fails, an OS-assigned free port.
- Routes (path matched after stripping the query, then `urllib.parse.unquote`): `/` newest screen; `/s/<name>` that screen (plain file name listed by `list_screens`, else 404); `/api/screens` → `{"screens": [{"name": str, "mtime": float}], "newest": str|null}`; `/files/<path>` file inside `screens/` (resolved path must stay inside, else 404); anything else 404. Screens are `*.html` files not starting with `.`, sorted by mtime ascending then name; a missing `screens/` dir is an empty list.
- Pages are `text/html; charset=utf-8`. Request logging is off (`log_message` does nothing); `server.log` gets one line at start, one at exit, and tracebacks.
- Frame contract: `frame.html` holds `{{TITLE}}`, `{{CONTENT}}`, `{{BOOT}}` exactly once each, replaced in one `re.sub` pass so placeholder text inside content stays literal. `{{TITLE}}` = `html.escape` of the first `<h1>`'s text (tags stripped, whitespace collapsed), else the file name. `{{BOOT}}` sits in `<script id="sm-boot" type="application/json">{{BOOT}}</script>` and is `json.dumps(boot).replace("</", "<\\/")` with boot keys exactly `screen` (str|null), `newest` (str|null), `screens` (as in `/api/screens`), `project` (project dir's name), `address` (`<url_host>:<port>`). Element ids: `sm-tabs` (tab bar), `sm-content` (wraps `{{CONTENT}}`), `sm-status` (status bar), `sm-banner` (stopped banner). `{{CONTENT}}` is the sole child of `#sm-content` (whitespace aside); the empty state and any other frame markup live outside it.
- Full documents (content whose `lstrip().lower()` starts with `<!doctype` or `<html`) are served unchanged except for `server.POLL_SCRIPT`, a `<script data-show-me-poll>…</script>` inserted before the last `</body>` (case-insensitive), or appended when there is none.
- Poll rule (frame and `POLL_SCRIPT`): `GET /api/screens` every 1000 ms; when `newest` differs from `boot.newest`, `location.href = "/"`. On a failed poll the frame turns the live dot red and shows `#sm-banner`, and the interval grows by 1000 ms per failure up to 5000 ms; the first success after a failure reloads (or goes to `/` when `newest` changed).
- Theme: `data-theme="light"|"dark"` on `<html>` overrides `prefers-color-scheme`; the choice is stored in `localStorage` key `show-me-theme`, every access wrapped in try/catch.
- Libraries, exact URLs: `https://cdn.jsdelivr.net/npm/mermaid@11.4.1/dist/mermaid.esm.min.mjs`, `https://cdnjs.cloudflare.com/ajax/libs/highlight.js/11.9.0/highlight.min.js`; fonts from `fonts.googleapis.com` / `fonts.gstatic.com`. No other external hosts.
- Component classes (frame CSS, `components.md`, and evals use these names): `diagram`, `compare`, `option`, `letter`, `note`, `mock`, `mock-bar`, `mock-url`, `mock-body`, `mock-nav`, `mock-tabs`, `mock-form`, `mock-actions`, `field`, `input`, `toggle`, `btn`, `placeholder`, `pin`, `legend`, `tree`, `tree-head`, `row` (children `k`, `t`, `v`, `n`; attribute `data-depth`), `trace`, `trace-steps`, `callout` (variant `callout warn`), state class `on`. Markup shapes:
  - diagram: `<figure class="diagram"><pre class="mermaid">…</pre><figcaption>…</figcaption></figure>` (caption optional; `class X accent` in the Mermaid source marks a node amber)
  - compare: `<div class="compare"><figure class="option"><figcaption><span class="letter">A</span>Title</figcaption>…<p class="note">…</p></figure>…</div>`
  - annotations: `<b class="pin">1</b>` inside the annotated element, and `<ol class="legend"><li><b class="pin">1</b>…</li></ol>`
  - tree: `<div class="tree"><div class="tree-head"><span>title</span><span>meta</span></div><div class="row" data-depth="0"><span class="k">…</span><span class="t">…</span><span class="v">…</span><span class="n">…</span></div>…</div>`
  - trace: `<div class="trace"><ol class="trace-steps"><li><span class="fn">name</span><span class="loc">file:line</span></li>…</ol><pre data-start="88" data-hl="4" data-why="…"><code class="language-python">…</code></pre>…</div>` (one `pre` per step, same order; the frame JS builds the step buttons, the why panel, the prev/next bar, and arrow-key stepping)
- Skill voice: "your human partner" in skill bodies (the frontmatter description says "the user"), plain declaratives with the reason attached, no MUST/NEVER capitals.
- Commits: Conventional Commits with scope `show-me` (`feat(show-me): …`, `test(show-me): …`, `docs(show-me): …`).
- Eval runs: Agent tool, `model: opus`, one subagent per run, prompt shape from `skills/writing-skills/references/eval-workflow.md` Step 1. Workspaces under `$SCRATCH/show-me-evals/iteration-N/eval-<id>-<name>/{with_skill,without_skill}/run-K/`, `$SCRATCH` = this session's scratchpad. Grade into `grading.json` (`expectations[{text, passed, evidence}]` + `summary{total, passed, failed, pass_rate}`); read every mechanical hit before counting it. Stop every server an eval run started.

## Review Focus

1. Screen names with spaces or Vietnamese letters (`sơ đồ.html`): `/s/<name>` must decode them and boot must carry them intact. Pinned in Task 1 `test_named_screen_with_non_ascii_name`.
2. A `server.json` whose pid now belongs to some other live process: `start` must not report it as running and `stop` must not kill it. Pinned in Task 2 `test_stale_pid_is_neither_reused_nor_killed`.

import http.client
import importlib.util
import json
import os
import re
import tempfile
import threading
import unittest
from pathlib import Path
from urllib.parse import quote

ROOT = Path(__file__).resolve().parents[2]
SCRIPTS = ROOT / "skills" / "show-me" / "scripts"
KEY = "0123456789abcdef0123456789abcdef"


def load_server():
    spec = importlib.util.spec_from_file_location("show_me_server", SCRIPTS / "server.py")
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module


srv = load_server()


def boot_of(body):
    m = re.search(r'<script id="sm-boot" type="application/json">(.*?)</script>', body, re.S)
    assert m, "no sm-boot script in page"
    return json.loads(m.group(1))


class Resp:
    def __init__(self, status, headers, body):
        self.status, self.headers, self.body = status, headers, body

    def header(self, name):
        return self.headers.get(name.lower())


class AppTest(unittest.TestCase):
    def setUp(self):
        self.tmp = tempfile.TemporaryDirectory()
        self.root = Path(self.tmp.name)
        self.screens = self.root / "screens"
        self.screens.mkdir()
        self.port = self.serve("demo")

    def serve(self, project):
        httpd = srv.make_server(self.screens, KEY, "127.0.0.1", 0, "localhost", project, SCRIPTS / "frame.html")
        threading.Thread(target=httpd.serve_forever, daemon=True).start()
        self.addCleanup(httpd.server_close)
        self.addCleanup(httpd.shutdown)
        return httpd.server_address[1]

    def tearDown(self):
        self.tmp.cleanup()

    def get(self, path, cookie=None, port=None):
        conn = http.client.HTTPConnection("127.0.0.1", port or self.port, timeout=5)
        conn.request("GET", path, headers={"Cookie": cookie} if cookie else {})
        r = conn.getresponse()
        resp = Resp(r.status, {k.lower(): v for k, v in r.getheaders()}, r.read().decode("utf-8"))
        conn.close()
        return resp

    def authed(self, path, port=None):
        sep = "&" if "?" in path else "?"
        return self.get(path + sep + "key=" + KEY, port=port)

    def write(self, name, text, mtime):
        p = self.screens / name
        p.write_text(text, encoding="utf-8")
        os.utime(str(p), (mtime, mtime))

    def test_no_key_is_403_on_every_route(self):
        for path in ["/", "/api/screens", "/s/a.html", "/files/a.svg", "/nope"]:
            self.assertEqual(self.get(path).status, 403, path)

    def test_wrong_key_is_403(self):
        self.assertEqual(self.get("/?key=" + "f" * 32).status, 403)

    def test_query_key_sets_cookie_named_by_port(self):
        r = self.authed("/")
        self.assertEqual(r.status, 200)
        cookie = r.header("Set-Cookie")
        self.assertTrue(cookie.startswith("show_me_key_%d=%s" % (self.port, KEY)), cookie)
        for attr in ("HttpOnly", "SameSite=Strict", "Path=/"):
            self.assertIn(attr, cookie)

    def test_cookie_alone_passes(self):
        r = self.get("/api/screens", cookie="show_me_key_%d=%s" % (self.port, KEY))
        self.assertEqual(r.status, 200)

    def test_cookie_for_another_port_fails(self):
        r = self.get("/api/screens", cookie="show_me_key_%d=%s" % (self.port + 1, KEY))
        self.assertEqual(r.status, 403)

    def test_api_screens_sorted_by_mtime_skipping_hidden_and_non_html(self):
        self.write("b.html", "<p>b</p>", 1000)
        self.write("a.html", "<p>a</p>", 2000)
        self.write(".draft.html", "<p>hidden</p>", 3000)
        self.write("notes.txt", "not a screen", 4000)
        data = json.loads(self.authed("/api/screens").body)
        self.assertEqual([s["name"] for s in data["screens"]], ["b.html", "a.html"])
        self.assertEqual(data["screens"][0]["mtime"], 1000)
        self.assertEqual(data["newest"], "a.html")

    def test_missing_screen_dir_is_an_empty_list_and_empty_page(self):
        self.screens.rmdir()
        self.assertEqual(json.loads(self.authed("/api/screens").body), {"screens": [], "newest": None})
        r = self.authed("/")
        self.assertEqual(r.status, 200)
        boot = boot_of(r.body)
        self.assertIsNone(boot["screen"])
        self.assertEqual(boot["screens"], [])

    def test_fragment_is_wrapped_in_frame(self):
        self.write("flow.html", "<h1>Luồng <em>đăng   nhập</em></h1>\n<p>body</p>", 1000)
        r = self.authed("/")
        self.assertEqual(r.status, 200)
        self.assertEqual(r.header("Content-Type"), "text/html; charset=utf-8")
        self.assertIn("<title>Luồng đăng nhập</title>", r.body)
        self.assertRegex(r.body, r'id="sm-content"[^>]*>\s*<h1>Luồng <em>đăng   nhập</em></h1>\n<p>body</p>')
        self.assertEqual(boot_of(r.body), {
            "screen": "flow.html", "newest": "flow.html",
            "screens": [{"name": "flow.html", "mtime": 1000}],
            "project": "demo", "address": "localhost:%d" % self.port,
        })

    def test_title_falls_back_to_file_name(self):
        self.write("no-heading.html", "<p>x</p>", 1000)
        self.assertIn("<title>no-heading.html</title>", self.authed("/").body)

    def test_full_document_is_served_as_is_with_poll_script(self):
        doc = "<!DOCTYPE html>\n<html><head><title>Mine</title></head><body><p>own</p></body></html>"
        self.write("full.html", doc, 1000)
        body = self.authed("/").body
        self.assertTrue(body.startswith("<!DOCTYPE html>"))
        self.assertNotIn('id="sm-tabs"', body)
        self.assertIn("<p>own</p>", body)
        self.assertLess(body.index("data-show-me-poll"), body.rindex("</body>"))

    def test_named_screen_with_non_ascii_name(self):
        self.write("sơ đồ.html", "<h1>Cũ</h1>", 1000)
        self.write("moi.html", "<h1>Mới</h1>", 2000)
        r = self.authed("/s/" + quote("sơ đồ.html"))
        self.assertEqual(r.status, 200)
        self.assertIn("<h1>Cũ</h1>", r.body)
        boot = boot_of(r.body)
        self.assertEqual(boot["screen"], "sơ đồ.html")
        self.assertEqual(boot["newest"], "moi.html")

    def test_unknown_or_escaping_screen_is_404(self):
        self.assertEqual(self.authed("/s/missing.html").status, 404)
        self.assertEqual(self.authed("/s/" + quote("../frame.html", safe="")).status, 404)

    def test_files_route_serves_assets_and_rejects_traversal(self):
        (self.screens / "img.svg").write_text("<svg xmlns='http://www.w3.org/2000/svg'/>", encoding="utf-8")
        (self.root / "secret.txt").write_text("secret", encoding="utf-8")
        r = self.authed("/files/img.svg")
        self.assertEqual(r.status, 200)
        self.assertEqual(r.header("Content-Type"), "image/svg+xml")
        self.assertEqual(self.authed("/files/../secret.txt").status, 404)
        self.assertEqual(self.authed("/files/%2e%2e/secret.txt").status, 404)

    def test_placeholder_text_inside_a_fragment_stays_literal(self):
        self.write("raw.html", "<p>{{TITLE}} {{CONTENT}} {{BOOT}}</p>", 1000)
        body = self.authed("/").body
        self.assertIn("<p>{{TITLE}} {{CONTENT}} {{BOOT}}</p>", body)
        self.assertEqual(boot_of(body)["screen"], "raw.html")

    def test_boot_survives_script_close_in_project_name(self):
        port = self.serve("a</script>b")
        body = self.authed("/", port=port).body
        self.assertEqual(boot_of(body)["project"], "a</script>b")

import importlib.util
import json
import os
import socket
import subprocess
import sys
import tempfile
import time
import unittest
import urllib.request
from pathlib import Path

ROOT = Path(__file__).resolve().parents[2]
SERVER = ROOT / "skills" / "show-me" / "scripts" / "server.py"
KEYS = {"url", "screen_dir", "session_dir", "port", "pid", "reused"}


def load_server():
    spec = importlib.util.spec_from_file_location("show_me_server_cli", SERVER)
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module


def clean_env(**extra):
    env = {k: v for k, v in os.environ.items() if k != "SSH_CONNECTION"}
    env.update(extra)
    return env


def run(*args, env=None, cwd=None):
    return subprocess.run([sys.executable, str(SERVER)] + list(args), stdout=subprocess.PIPE,
                          stderr=subprocess.PIPE, universal_newlines=True,
                          env=env or clean_env(), cwd=cwd, timeout=30)


def fetch(url):
    with urllib.request.urlopen(url, timeout=5) as r:
        return r.status


class CliTest(unittest.TestCase):
    def setUp(self):
        self.tmp = tempfile.TemporaryDirectory()
        self.base = Path(self.tmp.name)
        self.project = self.base / "proj"
        self.project.mkdir()
        self.session = self.project / ".superpowers" / "show-me"

    def tearDown(self):
        run("stop", "--project-dir", str(self.project))
        self.tmp.cleanup()

    def start(self, *extra, env=None):
        r = run("start", "--project-dir", str(self.project), *extra, env=env)
        self.assertEqual(r.returncode, 0, r.stderr)
        lines = r.stdout.strip().splitlines()
        self.assertEqual(len(lines), 1, r.stdout)
        return json.loads(lines[0])

    def info(self):
        return json.loads((self.session / "server.json").read_text())

    def test_start_prints_contract_and_writes_session(self):
        out = self.start()
        self.assertEqual(set(out), KEYS)
        self.assertFalse(out["reused"])
        self.assertEqual(Path(out["session_dir"]), self.session.resolve())
        self.assertEqual(Path(out["screen_dir"]), (self.session / "screens").resolve())
        self.assertTrue(Path(out["screen_dir"]).is_dir())
        self.assertEqual((self.session / ".gitignore").read_text(), "*\n")
        info = self.info()
        self.assertEqual(set(info), {"pid", "port", "host", "url", "key", "started_at"})
        self.assertRegex(info["key"], r"^[0-9a-f]{32}$")
        self.assertEqual(info["host"], "127.0.0.1")
        self.assertEqual(info["pid"], out["pid"])
        self.assertEqual(out["url"], "http://localhost:%d/?key=%s" % (out["port"], info["key"]))
        self.assertEqual(fetch(out["url"]), 200)

    def test_start_twice_reuses_the_running_server(self):
        first = self.start()
        second = self.start()
        self.assertTrue(second["reused"])
        self.assertEqual((second["port"], second["pid"], second["url"]),
                         (first["port"], first["pid"], first["url"]))

    def test_status_and_stop_exit_codes(self):
        out = self.start()
        st = run("status", "--project-dir", str(self.project))
        self.assertEqual(st.returncode, 0)
        self.assertEqual(json.loads(st.stdout)["pid"], out["pid"])
        self.assertEqual(run("stop", "--project-dir", str(self.project)).returncode, 0)
