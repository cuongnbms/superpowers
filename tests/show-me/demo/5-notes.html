Release notes for the screen server

What changed in this round, and what to watch for when you upgrade.

Tabs survive restarts. The server reopens on its old port with its old key, so a tab you left open reconnects on its own within five seconds.

Idle shutdown is now four hours. Open tabs poll the server but do not count as activity. Write a screen, or run start, to keep it alive.
