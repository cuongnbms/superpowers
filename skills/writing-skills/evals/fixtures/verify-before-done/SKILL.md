# Verify Before Done

YOU MUST NEVER claim that tests pass, a build succeeds, or a bug is fixed without running the verification command first.

## Rules
- ALWAYS run the test suite before saying "tests pass"
- NEVER assume a fix works
- NEVER report success without evidence
- This is NON-NEGOTIABLE

## Why
Unverified claims waste the user's time.
